[pyvinecopulib](https://github.com/vinecopulib/pyvinecopulib) is the Python binding of vinecopulib, the reference C++ implementation of vine copulas. This page reports what `benchmarks/compare_pyvinecopulib.py` measures when both libraries solve the same problem, and it does not hide the result: **rscopulas selects the same or a better model and is currently 1.6–2.7× slower at select-and-fit** with a rich parametric family set.

<Note>
Numbers below come from one run on 2026-09-10 on an otherwise idle Apple M3 Pro (macOS 15.5, Python 3.12, rscopulas 0.4.0 built from source with the maximum-likelihood pair fitters, pyvinecopulib 0.7.6, NumPy 2.5). Absolute times are single-run medians of three fits and should be read as ±20 %. The full report, including every first-tree edge, is committed as `docs/pyvinecopulib-comparison.md`.
</Note>

## Summary

| Dataset | rscopulas fit (AIC) | pyvinecopulib fit (BIC) | Ratio | Test log-lik: rscopulas / pyvinecopulib / truth | Rosenblatt KS max: rscopulas / pyvinecopulib / truth |
| --- | ---: | ---: | ---: | --- | --- |
| Gaussian R-vine, d = 5 | 3.1 s | 1.7 s | 1.8× | 2607.6 / 2607.6 / 2609.0 | 0.023 / 0.023 / 0.021 |
| Mixed R-vine, d = 5 | 3.4 s | 1.3 s | 2.7× | 4450.8 / 4443.8 / 4644.5 | 0.029 / 0.021 / 0.019 |
| Mixed R-vine, d = 8 | 6.5 s | 4.1 s | 1.6× | 7407.1 / 7391.2 / 7690.2 | 0.038 / 0.029 / 0.028 |

Each fit selects structure and families on 2000 training rows; log-likelihoods are evaluated on 2000 held-out rows. Fit times are medians of three complete `fit_r` / `Vinecop.from_data` calls.

## What the numbers say

- **Under the same criterion the two libraries fit the same model.** With BIC, rscopulas selects exactly the model pyvinecopulib selects on all three datasets: identical in-sample and out-of-sample log-likelihood and parameter count. The pair-copula fitters are maximum-likelihood on both sides, so agreement is expected once the candidate set and criterion match.
- **rscopulas' AIC default is better out of sample on the mixed vines.** AIC keeps a few more parameters (14 vs 13 at d = 5, 35 vs 30 at d = 8) and pays off on the held-out rows: 4450.8 vs 4443.8 nats at d = 5 and 7407.1 vs 7391.2 at d = 8. On the Gaussian vine both criteria pick the same ten-parameter model. Rosenblatt calibration of the test set is comparable; pyvinecopulib's transform is slightly more uniform per column (largest KS distance 0.021–0.029 vs 0.023–0.038), rscopulas' columns are slightly less correlated at d = 8.
- **Both libraries lose the same information to structure selection.** On the mixed datasets the simulating vine scores 200–300 nats higher out of sample than either fit because Kendall's τ spanning trees pick a different first tree from the truth. That is a property of the Dißmann algorithm, not of either implementation, and it affects both equally.
- **Speed is the remaining gap, and it has narrowed.** With independence, Gaussian, Student-t, Clayton, Frank, Gumbel, Joe, BB1 and BB7 as candidates (rotations allowed), rscopulas needs 3.1–6.5 s where pyvinecopulib needs 1.3–4.1 s, a factor of 1.6–2.7. Before the 0.4.0 estimation rewrite the same run took 18–45 s. Part of the remaining difference is that pyvinecopulib prunes candidate families from the empirical symmetry of each pair (`preselect_families=True`, its default) while rscopulas scores every candidate.

The cross-language harness on the [Benchmarks](/performance/benchmarks) page tells a different story for `log_pdf` and sampling, where rscopulas is far ahead of R; the two pages measure different things and should be read together.

## Method

The ground truth never touches rscopulas. Three known vines are built with pyvinecopulib and simulated with `Vinecop.simulate`:

<AccordionGroup>
  <Accordion title="Gaussian R-vine (d = 5)">
    Random R-vine structure (`RVineStructure.simulate`) with Gaussian pair copulas whose correlations decay from ±0.75 in the first tree to 0.1 in the last.
  </Accordion>
  <Accordion title="Mixed R-vine (d = 5)">
    Clayton, Gumbel (0°, 90°, 180°, 270°), Frank and Student-t edges: tail dependence of both signs in the first tree, weaker mixed dependence deeper down.
  </Accordion>
  <Accordion title="Mixed R-vine (d = 8)">
    28 edges cycling through the same families and rotations, with dependence weakening tree by tree down to near-independent Gaussian edges.
  </Accordion>
</AccordionGroup>

Each simulation yields 2000 training rows and 2000 test rows, rank-transformed separately in NumPy (`rank / (n + 1)`). Both libraries then select from the same candidate set with Kendall's τ maximum spanning trees, each with its own default selection criterion: `VineCopula.fit_r` defaults to **AIC**, `FitControlsVinecop` to **BIC**. A third configuration refits rscopulas with BIC to separate the criterion from the implementation. Both run single-threaded in one Python process.

Per dataset the script reports fit wall time (median of three runs), the family, rotation and parameters of every first-tree edge next to the truth, in-sample and out-of-sample log-likelihood (each model's own density summed over the pseudo-observations, with the simulating vine as reference), and two uniformity diagnostics of the test set's Rosenblatt transform under each fitted model: the largest per-column Kolmogorov–Smirnov distance from U(0, 1) with its asymptotic p-value, and the largest absolute Spearman correlation between transformed columns.

## Reproducing

```bash
pip install pyvinecopulib          # next to an installed rscopulas build
python benchmarks/compare_pyvinecopulib.py                 # full run, about 2 minutes
python benchmarks/compare_pyvinecopulib.py --repeats 1 --n-train 500 --n-test 500 --dataset mixed_rvine_5d
```

The script writes `benchmarks/output/pyvinecopulib-comparison.md` and `.json` (gitignored) and a committed copy of the Markdown report to `docs/pyvinecopulib-comparison.md`.
