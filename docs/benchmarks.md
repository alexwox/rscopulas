# Benchmarks

There are **two** complementary benchmarking surfaces. They share the same **fixture JSON** as tests where noted, but **methodology differs** — do not compare numbers across them naively.

## 1. Cross-language harness (`benchmarks/`)

**What it measures:** Wall-clock time for end-to-end workloads in **Rust**, **Python**, and **R** on the same inputs.

**Driver:** `python benchmarks/run.py` (see [benchmarks/README.md](../benchmarks/README.md)).

**Manifest:** [benchmarks/cases.json](../benchmarks/cases.json) lists cases, fixture paths, iteration counts, and which implementations run.

**Coverage (default manifest) includes:**

- Single-family: `log_pdf`, `fit`, `sample`
- Pair copula: density and **h / hinv** kernels (including **`pair_khoudraji_kernels`** → `fixtures/reference/r-copula/v1_1_3/khoudraji_pair_case01.json`)
- Mixed R-vine: `log_pdf`, `sample`, `fit`

**Outputs:** Written under `benchmarks/output/` (e.g. `latest.json`, `latest.md`). That directory is gitignored except `.gitignore`; results are **local**.

**Rust binary:** Built as the `rscopulas` example `benchmark_runner` (invoked by the orchestrator).

## 2. Criterion benches (`rscopulas`, sources under `crates/rscopulas-core/benches/`)

**What it measures:** Microbenchmark statistics (typically per-iteration) for Rust-only code paths.

**Notable targets:**

- `cross_language.rs` — reads `benchmarks/cases.json` and benches Rust operations for cases that request `"rust"` (uses `ExecPolicy::Force(Device::Cpu)` for stable CPU timing).
- `gaussian.rs` — additional Gaussian-focused scenarios.

**Output:** Printed to the terminal / Criterion reports, not the harness `latest.json`.

## 3. Comparison against pyvinecopulib (`benchmarks/compare_pyvinecopulib.py`)

**What it measures:** How rscopulas' R-vine selection and fitting compares with
[pyvinecopulib](https://github.com/vinecopulib/pyvinecopulib) (the Python
binding of vinecopulib) on the same data, in wall time and in statistical
quality. Results: [docs/pyvinecopulib-comparison.md](pyvinecopulib-comparison.md)
(committed copy) and `benchmarks/output/pyvinecopulib-comparison.{md,json}`
(gitignored, regenerated by the script).

**Ground truth independent of rscopulas.** Three known vines are built and
simulated with pyvinecopulib only:

| Dataset | Structure | Edges |
| --- | --- | --- |
| `gaussian_rvine_5d` | random R-vine (`RVineStructure.simulate`) | Gaussian, ρ from ±0.75 in tree 1 to 0.1 in tree 4 |
| `mixed_rvine_5d` | random R-vine | Clayton, Gumbel (0°/90°/180°/270°), Frank, Student-t |
| `mixed_rvine_8d` | random R-vine | 28 edges mixing the same families and rotations, weakening with tree depth |

Each simulation (`Vinecop.simulate`, fixed seed) yields `n_train = 2000` rows
for selection/fitting and `n_test = 2000` held-out rows; both splits are
rank-transformed separately in NumPy (`rank / (n + 1)`).

**Same candidate set, each library's default criterion.** Both libraries select
structure (Kendall's τ maximum spanning trees) and pair-copula families from
independence, Gaussian, Student-t, Clayton, Frank, Gumbel, Joe, BB1 and BB7 with
rotations allowed. rscopulas `VineCopula.fit_r` defaults to **AIC**;
pyvinecopulib `FitControlsVinecop` defaults to **BIC** and to
`preselect_families=True`, which prunes candidate families from the empirical
symmetry of each pair before fitting — rscopulas fits every candidate. A third
configuration refits rscopulas with BIC so the criterion effect can be separated
from the implementation effect. Both run single-threaded in one Python process.

**Reported per dataset:**

- fit wall time, median of 3 complete select-and-fit calls (and its ratio);
- selected family, rotation and parameters of every first-tree edge next to the
  truth (edge sets can differ between libraries when Kendall's τ ties are broken
  differently);
- in-sample and out-of-sample log-likelihood of each fitted model, next to the
  simulating vine's own log-likelihood on the same pseudo-observations;
- Rosenblatt uniformity of the **test** set under each fitted model: the largest
  per-column Kolmogorov–Smirnov distance from U(0, 1) with its asymptotic
  p-value, and the largest absolute Spearman correlation between transformed
  columns. A well-specified model makes both small; the truth row calibrates
  what "small" means at this sample size.

**Run it:**

```bash
python benchmarks/compare_pyvinecopulib.py                # full run, ~10 minutes
python benchmarks/compare_pyvinecopulib.py --repeats 1 --n-train 500 --n-test 500 --dataset mixed_rvine_5d
```

Requires `pyvinecopulib` (`pip install pyvinecopulib`) next to an installed
rscopulas build.

## Reproducing results

**Harness (all implementations):**

```bash
python benchmarks/run.py
```

Filter:

```bash
python benchmarks/run.py --implementation rust --case vine
```

**Criterion (Rust only):**

```bash
cargo bench -p rscopulas
```

## What not to infer

- Harness times include interpreter / FFI / JSON load overhead for Python and R; Criterion benches do not.
- Relative speed vs R in `latest.md` is **machine-dependent**; use for regression tracking on a fixed runner, not as absolute marketing numbers without context.
